<!-- SOBRE O PROJETO -->
<h2>💡 Sobre o Projeto</h2>

<p>
  A <b>Turma do Bem (TdB)</b> é uma OSCIP que gerencia uma vasta rede de voluntariado odontológico para atender crianças, jovens e mulheres em situação de vulnerabilidade social. O objetivo deste Challenge é desenvolver uma solução tecnológica modular e escalável para centralizar cadastros, estruturar o funil de captação e integrar IA nos processos da instituição.
</p>
